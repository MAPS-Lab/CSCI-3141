# Week 4 extras

Notebooks used live in class. Open them in JupyterLab or VS Code and run the cells from top to bottom.

- `class-07-live-python.ipynb`, `class-07-live-r.ipynb`: Class 07, table manipulation and graphics, built step by step to the saved genre summary, figure and exclusion record.
- `class-08-live-python.ipynb`, `class-08-live-r.ipynb`: Class 08, building, rendering and parameterizing a reproducible report.
- `class-08-iris.ipynb`, `class-08-iris.Rmd`, `class-08-steam.ipynb`, `class-08-steam.Rmd`, `steam_achievements.csv`: the complete report sources the Class 08 notebooks render. Keep them in the same folder as the notebooks.

## What you need

- Python: pandas, NumPy, Matplotlib, seaborn, scikit-learn, Jupyter and nbconvert.
- R: dplyr, ggplot2, knitr, rmarkdown, and the IRkernel package to run R inside Jupyter (`install.packages("IRkernel"); IRkernel::installspec()`).
- PDF rendering in Class 08 also needs Pandoc and XeLaTeX.
